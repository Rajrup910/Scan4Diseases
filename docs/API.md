# API Reference

Base URL in development: `http://localhost:8000`
Interactive docs: `/docs` (Swagger UI) and `/redoc`.

All errors share one shape:

```json
{
  "error": "image_quality_insufficient",
  "message": "Image quality is insufficient for screening. The image appears blurred...",
  "detail": "optional, non-sensitive extra context"
}
```

`error` is a stable machine-readable code — branch on it. `message` is safe to display to a
user verbatim, in the requested language where applicable. Filesystem paths, stack traces
and internal state never appear in a response.

---

## `GET /health`

Component status. Always returns 200 — it describes what is working rather than failing.

```json
{
  "status": "ok",
  "version": "0.1.0",
  "model_loaded": true,
  "model_arch": "efficientnet_b0",
  "class_mapping_version": "1.0.0",
  "num_classes": 7,
  "llm_available": true,
  "device": "cuda",
  "stub_mode": false
}
```

| Field | Meaning |
|---|---|
| `model_loaded` | A checkpoint is loaded. If false, `/predict` returns 503 unless `stub_mode`. |
| `llm_available` | Ollama responded. If false, `/predict` still works; `/chat` returns 503. |
| `stub_mode` | **Predictions are synthetic.** Must be false for any demo or evaluation. |

## `POST /predict`

The main screening endpoint. `multipart/form-data`, because it carries an image file.

### Request

| Field | Type | Required | Notes |
|---|---|---|---|
| `image` | file | yes | JPEG, PNG, WebP or BMP. Max 10 MB, min 64×64. EXIF rotation is honoured. |
| `questionnaire` | string | no | JSON object, see below. Omitted means "not answered". |
| `language` | string | no | `en` (default) or `hi`. |
| `include_explanation` | bool | no | Default `true`. Set `false` to skip the LLM and respond faster. |

Questionnaire fields — **all optional**. A missing field means *not reported*, and is never
treated as "no".

| Field | Type |
|---|---|
| `duration` | `less_than_1_month` \| `1_to_3_months` \| `3_to_12_months` \| `more_than_1_year` \| `unknown` |
| `size_change` | `growing` \| `stable` \| `shrinking` \| `unknown` |
| `recent_change`, `itching`, `pain`, `bleeding`, `color_change`, `family_history` | boolean |
| `sun_exposure` | string |

Unknown fields are **rejected**, so a typo surfaces as a 422 rather than being silently
ignored.

```bash
curl -X POST http://localhost:8000/predict \
  -F "image=@lesion.jpg" \
  -F 'questionnaire={"bleeding":true,"duration":"3_to_12_months","size_change":"growing"}' \
  -F "language=en"
```

### Response — 200

```json
{
  "request_id": "a1b2c3d4e5f6g7h8",
  "language": "en",

  "predicted_class": "bcc",
  "predicted_name": "Basal cell carcinoma",
  "confidence": 0.81,
  "probabilities": [
    {"code": "bcc", "name": "Basal cell carcinoma", "probability": 0.81, "malignancy": "malignant"},
    {"code": "akiec", "name": "Actinic keratosis", "probability": 0.09, "malignancy": "premalignant"}
  ],

  "image_quality": {
    "acceptable": true,
    "blur_score": 471.25,
    "brightness": 150.63,
    "width": 1022,
    "height": 767,
    "warnings": []
  },

  "gradcam_url": "/gradcam/gradcam_ybo1qjyuT0s34UQwGv24WQ.png",
  "gradcam_focus": "concentrated on the central region of the image",

  "triage": {
    "category": "urgent_evaluation",
    "label": "Urgent medical evaluation",
    "advice": "Please seek medical evaluation without delay...",
    "reasons": [
      "The screening model's leading category is one that can be cancerous.",
      "A lesion that bleeds without being injured should be examined promptly."
    ],
    "rule_ids": ["R1_malignant_class", "R8_bleeding", "flag_bleeding"],
    "low_confidence": false
  },

  "questionnaire": {"bleeding": true, "duration": "3_to_12_months", "itching": null},

  "explanation": "What the scan found...",
  "explanation_available": true,
  "disclaimer": "IMPORTANT\n\nThis result is generated by an AI screening system...",

  "model_arch": "efficientnet_b0",
  "stub": false,
  "inference_ms": 84.3
}
```

### Client obligations

1. **Always display `disclaimer`.** It is produced by the application, not the model, and
   must not be truncated or paraphrased.
2. **Never render `confidence` as a disease probability.** "The model gave its highest score
   (81%) to this category", not "81% chance you have this". This is not a style preference —
   see section 16 of the master specification.
3. **`triage.category` is authoritative.** Do not re-derive urgency on the client.
4. **Handle `explanation_available: false`.** The LLM is optional; everything else is not.
5. **Check `stub`.** If true, show that these are placeholder values.
6. `probabilities` arrives sorted descending.

### Errors

| Status | `error` | Cause |
|---|---|---|
| 422 | `empty_upload` | No file received |
| 422 | `file_too_large` | Over the configured size limit |
| 422 | `unsupported_format` | Not a supported image type |
| 422 | `corrupt_image` | Truncated or damaged file |
| 422 | `image_too_small` | Below 64×64 |
| 422 | `image_quality_insufficient` | Blurred, too dark, overexposed, or below the model resolution |
| 422 | `invalid_questionnaire` | Malformed JSON, bad value, or unknown field |
| 422 | `invalid_request` | Missing required field |
| 500 | `inference_failed` | Model raised at inference time |
| 503 | `model_unavailable` | No checkpoint loaded and stub mode off |

## `GET /gradcam/{filename}`

Returns the PNG overlay referenced by `gradcam_url`, at the original image resolution.

Short-lived: files are deleted after `STORAGE_TTL_MINUTES` (default 15) and on shutdown.
A 404 after that is expected — re-run the scan. Path traversal is rejected.

Served with `Cache-Control: private, no-store` so no proxy retains a medical image.

## `POST /chat`

Follow-up conversation. `application/json`.

**Stateless.** The client echoes back the prediction context and prior turns; the server
keeps nothing between requests. There is no conversation store to leak.

```json
{
  "message": "What does basal cell carcinoma actually mean?",
  "language": "en",
  "prediction": {
    "predicted_class": "bcc",
    "confidence": 0.81,
    "triage_category": "urgent_evaluation",
    "low_confidence": false,
    "gradcam_focus": "concentrated on the central region of the image"
  },
  "questionnaire": {"bleeding": true},
  "history": [
    {"role": "user", "content": "What does this result mean?"},
    {"role": "assistant", "content": "The model gave its highest score..."}
  ]
}
```

`history` accepts only `user` and `assistant` roles — a `system` entry is rejected with 422,
which closes the obvious prompt-injection route from a client.

### Response — 200

```json
{
  "response": "Basal cell carcinoma is the most common kind of skin cancer...",
  "language": "en",
  "disclaimer": "IMPORTANT\n\n...",
  "filtered": false,
  "filter_reasons": []
}
```

`filtered: true` means the safety layer modified or replaced the model's output. The
response is still safe to display; the flag exists for logging and evaluation.

### Errors

| Status | `error` | Cause |
|---|---|---|
| 422 | `invalid_request` | Empty/oversized message, bad role in history |
| 503 | `llm_unavailable` | Ollama not reachable. **No fabricated answer is returned.** |

## Configuration

Every value comes from the environment or `.env` — see [`.env.example`](../.env.example).
The ones that change behaviour most:

| Variable | Default | Effect |
|---|---|---|
| `MODEL_CHECKPOINT` | `ml/checkpoints/deployed_model.pt` | Which model is served |
| `MODEL_ARCH` | `efficientnet_b0` | Must match the checkpoint |
| `ALLOW_STUB_MODEL` | `false` | Synthetic predictions when no checkpoint exists |
| `LOW_CONFIDENCE_THRESHOLD` | `0.60` | Below this, triage escalates |
| `CALIBRATION_TEMPERATURE` | `1.0` | From `evaluate.py --calibrate` |
| `STORAGE_TTL_MINUTES` | `15` | `0` disables overlay storage entirely |
| `LLM_ENABLED` | `true` | `false` skips the LLM cleanly |
| `LLM_BASE_URL` | `http://localhost:11434/v1` | Ollama's OpenAI-compatible endpoint |

## Notes for the mobile client

- Use the LAN IP of the machine running the backend, not `localhost`, and allow port 8000
  through Windows Firewall. On the Android emulator, `10.0.2.2` is the host.
- `include_explanation=false` gives a fast first response; call `/chat` afterwards for the
  narrative if you want a two-stage UI.
- Fetch `gradcam_url` promptly — it expires.
